# 合集网站精简功能设计

## 范围

本轮只完成四项功能：

1. 搜索作品名称和作者名称，并按 LAB、WCGlass、作者和作者自定义分类筛选。
2. 点击作品主图或预览图打开全屏灯箱，可关闭、左右切换并支持键盘操作。
3. 超级管理员创建作者及初始账号；作者登录后只能管理自己的资料、分类、作品和图片。
4. 作者粘贴微信笔记文字，系统识别作品名称、价格、环境和说明字段并填入作品表单；作者可以修改、手动上传图片并自行发布。

明确取消收藏、关注、通知、数据统计、操作日志、版本更新日志以及普通用户作者入驻申请。微信笔记不能直接读取微信或图片，不接入第三方服务。

## 搜索与筛选

全部作品页使用 URL 查询参数保存状态，支持 `q`、`author`、`category`、`environment` 和 `sort`。搜索匹配作品名称或作者名称；环境支持 LAB 和 WCGlass；分类选项随作者展示。排序仅保留最新发布和最近更新。查询在服务端通过 Prisma 执行，游客可使用。

## 图片灯箱

作品卡片图片在当前页面打开灯箱，不跳转详情页。灯箱显示当前图片、关闭按钮、上一张和下一张按钮；Escape 关闭，左右方向键切换。背景禁止滚动，图片保留原始比例。无复杂动画。

## 作者账号与权限

只有超级管理员可以创建作者账号。创建时同时生成作者资料、作者角色账号和唯一绑定关系，初始密码使用 Argon2id 保存并要求首次登录修改。作者后台保留资料、分类、作品和图片入口；所有写操作继续在服务端按作者归属校验。

不提供普通用户申请、认领或切换作者绑定的入口。

## 微信笔记智能填表

后台作品新建页增加文本粘贴区和“识别并填表”按钮。识别器使用稳定的本地规则匹配常见字段标题和人民币价格，不调用外部 AI：

- 作品名称
- 直购价
- 转发价
- LAB / WCGlass
- 功能说明
- 转发要求
- 购买须知

识别结果只填充当前浏览器中的作品表单，不直接写数据库。作者可修正识别内容、选择自己的分类、上传图片并点击发布。发布不需要管理员审核；无法识别的字段保持空白并提示作者补充。

## 验收

- 游客能搜索和筛选作品，刷新页面后筛选状态保留。
- 主图和预览图能在灯箱中查看并使用键盘关闭或切换。
- 超级管理员能创建作者账号，作者不能查看或修改其他作者内容。
- 常见微信笔记文本能自动填入作品表单，作者修正后可自行发布。
- 不新增第三方服务，不实现已取消功能。
