# 作者作品字段与后台列表调整

## 目标

- 每位作者独立决定以后新建、编辑作品时显示哪些说明字段。
- 字段可在作品表单中移除，也可随时添加回来。
- 已有作品的内容和公开卡片不受作者字段设置影响。
- 公开卡片严格保留作者输入的换行。
- 删除作品不再占用全部作品主列表。
- 从新建作品页面彻底移除微信笔记智能填表。

## 作者字段设置

作者表新增 `hiddenWorkFields`，只保存该作者隐藏的可选字段键。可管理字段为：功能说明、使用要求、获取方式、转发要求、购买须知、联系方式、其他说明。

新建和编辑作品页面只渲染当前未隐藏字段。每项提供“移除”；页面底部提供紧凑的“添加字段”区域。移除或添加会立即保存作者设置。作者本人、内容管理员和超级管理员均须先通过该作者的访问权限校验。

编辑旧作品时，隐藏字段不提交；服务端更新时从数据库保留这些字段原值，避免保存其他内容时清空旧数据。旧作品公开卡片继续按作品自身内容显示。

## 列表与文字

后台作品页默认排除 `DELETED`，增加“已删除”入口单独查看。已删除页保留超级管理员恢复功能。

所有说明文字使用 `white-space: pre-line`，保留单次换行，同时保持正常自动换行。

卡片显示顺序不再使用上下箭头。每一项右侧显示三横拖动柄，长按后可直接上下拖动排序，并兼容手机触摸操作。

## 删除微信笔记导入

移除新建作品表单中的导入卡片、组件、解析器及其专用测试，不影响普通手动填写和模板套用。

## 验证

- 两位作者隐藏字段互不影响。
- 移除后新建和编辑页不显示，添加后立即恢复。
- 编辑旧作品不会清空隐藏字段，公开页面仍显示旧内容。
- 卡片保留输入换行。
- 默认作品列表不显示已删除作品；已删除分类可查看和恢复。
- 新建作品页不存在微信笔记导入区域。
