# 手机底栏跳转延迟优化

## 目标

缩短首页、合集、我的三个底栏入口的首次点击等待时间，并让每次点击立即出现视觉反馈。网络请求仍可能存在短暂耗时，不承诺绝对零延迟。

## 方案

- 页面加载后主动预加载三个底栏目标路由。
- 用户触摸或鼠标按下入口时再次预加载目标路由。
- 点击非当前入口后立即显示临时选中状态，路由完成后由真实路径接管。
- 继续使用 Next.js 客户端路由，不整页刷新。
- 保留按压、弹跳、选中标记、返回后选中状态，以及再次点击当前入口回到顶部。
- 不修改底栏黑白灰视觉及其他页面。

## 验证标准

- 三个入口点击后立即改变选中状态。
- 首页、合集、我的均能正确跳转。
- 首次点击不会等待到路由完成才出现反馈。
- 重复点击不会产生重复跳转。
- 当前入口再次点击仍回到页面顶部。
- 手机视口下布局和动画不变。
